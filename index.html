Tempel link video untuk diunduh, atau tonton video YouTube tanpa iklan. Riwayat tidak disimpan.

Pengaturan server unduhan

GitHub Pages hanya menyajikan file statis, jadi pengambilan video dilakukan oleh server API yang kompatibel dengan Cobalt. Isi alamat servernya di sini.

Pemutar Invidious tidak memuat iklan YouTube. Jika video tidak muncul, server Invidious sedang penuh atau mati: ganti alamatnya dengan server lain. Pemutar nocookie tetap bisa menampilkan iklan.

Gunakan hanya untuk konten milikmu atau yang boleh diunduh. Patuhi aturan situs sumber dan hak cipta.
